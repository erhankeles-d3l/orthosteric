# Objective Reports

Home for per-objective task reports required by `docs/IMPLEMENTATION_PROTOCOL_SCIENTIFIC.md` (Protocol §14 task report) and the `CLAUDE.md` §17 task audit.

Established by `ADR-0006` (A1). No content is filed here retroactively — this directory holds reports from future objectives only, starting with the first objective committed after `ADR-0006` is Accepted.

One report per completed backlog objective (`docs/IMPLEMENTATION_BACKLOG.md`), named after the objective ID it documents.
